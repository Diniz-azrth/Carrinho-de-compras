# 🛒 Carrinho de Compras

Este projeto é um sistema de carrinho de compras interativo desenvolvido em JavaScript, HTML e CSS, onde o usuário pode selecionar produtos, definir a quantidade desejada, visualizar os itens adicionados e acompanhar o valor total da compra em tempo real.

## 🚀 Funcionalidades

* **Seleção de Produtos**: Permite escolher entre diferentes itens disponíveis (Fone de ouvido, Celular e Óculos VR).
* **Controle de Quantidade**: Define a quantidade desejada de cada produto a ser adicionada ao carrinho.
* **Cálculo de Totais**: Atualiza dinamicamente o valor parcial dos itens e o valor total da compra.
* **Limpeza do Carrinho**: Permite esvaziar a lista de produtos e reiniciar os valores do carrinho.

## 🛠️ Tecnologias Utilizadas

* **HTML5**: Estruturação semântica da interface do carrinho de compras.
* **CSS3**: Estilização visual customizada com layout em Grid e design responsivo.
* **JavaScript**: Manipulação do DOM, controle de arrays e lógica de cálculo de preços e quantidades.

## 📂 Estrutura do Projeto

* **index.html**: Arquivo principal com a estrutura da interface do projeto.
* **style.css**: Folha de estilos responsável pelo design e identidade visual.
* **js/app.js**: Script contendo a lógica de adição de produtos, cálculo do carrinho e limpeza.
* **assets/**: Pasta contendo imagens, ícones e arquivos SVG utilizados na interface.

## 📦 Como Rodar o Projeto

1. Clone o repositório em sua máquina.
2. Certifique-se de manter toda a estrutura de pastas e arquivos (`index.html`, `style.css`, a pasta `js/` e a pasta `assets/`) intacta.
3. Abra o arquivo `index.html` diretamente em qualquer navegador web para testar a aplicação.
